# Tymer voice set — Erinome, MISSION CONTROL ("nasa")
#
# A flight-controller set: every line is delivered like a control-room voice
# loop — the style, not the vocabulary. Procedure idiom applied to time itself
# is welcome ("T-plus six minutes, mark", "nominal", "advisory", "warning",
# "master alarm", "go for break", "acknowledge", "standby", "closeout");
# literal spaceflight nouns are not (launch, orbit, spacecraft, rocket, crew,
# astronaut, docking, re-entry, trajectory, Houston, countdown-to-launch).
# The content is always time, work and breaks.
#
# DOSAGE: the idiom is seasoning, not the dish — at most ONE control-room
# flourish per line; the rest is plain time/work language. A line that is all
# jargon is a failed line.
#
# The escalation ladder maps to ALERT LEVELS: nominal → advisory → caution →
# warning → alert → master alarm. Delivery stays controlled-professional the
# whole way — under pressure the voice gets faster, tighter and more clipped,
# never shouty. Control does not panic; that is the menace.
#
# The radio distortion is NOT generated — it is applied when the WAVs are
# converted for the app, by the `apollo` preset mapped to this set in
# build-tools/audio-presets.conf. The staged/promoted WAVs stay clean.
#
# @name below labels every file in this set `nasa-N.wav`, so it never
# collides with the other sets' filenames.
#
# Regenerate: see sound-prompts/README.md

@voice Erinome
@name nasa
@profile Tymer — the flight controller
@scene
A mission control room, lights low, rows of consoles. The controller speaks
into a headset on the voice loop — close-miked, calm, addressing one operator
who is mid-shift. It is hour six of the shift and this is the hundredth
callout of the day: pure routine. Every callout is brief, precise, and ends
cleanly; dead air is normal between calls.
@style
Flat, procedural control-room delivery — cold, detached, unemotional. Reading
telemetry, not talking to a friend: minimal inflection, no performance, no
smile in the voice, no reassurance. Clear, supported tone at a steady medium
pitch — never breathy, never creaky, absolutely no vocal fry; every word ends
clean and full, nothing trails off.
@pace
Clipped and even, with clean stops. Short sentences — voice-loop cadence, not
conversation. Pauses are tight: a [beat] is half a second at most, a breath on
the loop, never a long dramatic gap.
@accent Neutral American broadcast English, crisp consonants.
@context
The flight controller calls out the passage of a work or break period on the
loop. The voice is trusted because it is never dramatic — so when the alert
level rises, that carries real weight.
