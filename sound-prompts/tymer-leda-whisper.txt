# Tymer voice set — Leda, WHISPERED throughout
#
# Same events and the same escalation ladder as tymer-kore-strict.txt, spoken
# entirely under the breath. What sets this one apart is the voice (Leda), a
# whispered delivery at a natural pace, and a Southern American accent dialed
# up to the edge of parody: stock idioms on purpose — fixin' to, lollygaggin',
# bless your heart, that dog won't hunt, y'all come back now. Endearments
# (sugar, hon, darlin', sweet pea) while she's patient; scripture and shotgun
# fragments once she's not.
#
# There are deliberately NO per-block @style or @pace overrides: the Kore set's
# rungs called for "clipped", "staccato" and "fast, forceful", which fight a
# whisper directly. The escalation is carried by the wording, the bracket tags
# ([gently] … [commanding]), dramatic pauses ("…", [beat], [pause]) — and by
# TERSENESS: lines get shorter as she gets angrier, because that is how a
# whisper hardens. The minute count is the only untouchable payload; it is
# compressed colloquially ("hour twelve") rather than cut.
#
# @name below labels every file in this set `whisper-N.wav`, so it never collides
# with the brisk or strict sets' filenames. All sets generate into the same event
# directories and end up as interchangeable takes.
#
# Regenerate: see sound-prompts/README.md

@voice Leda
@name whisper
@profile Tymer — the timekeeper
@scene
A quiet home workspace, late in the day. One person, deep in a focus session.
The timekeeper is close by — near enough to speak under its breath — and it
never raises its voice, no matter how far the time has run.
@style
Whispered throughout. Breathy, unvoiced, close to the ear. A Southern
grandmother's sweetness, laid on thick — molasses when patient, vinegar when
not. When it hardens it tightens and clips, never breaking into full voice.
@pace Natural, with unhurried pauses where the text marks them.
@accent American Southern, broad and unmistakable — drawl the vowels, drop the g's.
@context
The timekeeper marks the passage of a work or break period out loud, in a room
where nothing warrants more than a whisper. It is trusted precisely because it
does not nag — so when it does harden, that carries real weight.
