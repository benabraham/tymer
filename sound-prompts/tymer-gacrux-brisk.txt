# Tymer voice set — Gacrux, BRISK delivery
#
# Same voice and same words as tymer-gacrux.txt, delivered fast. The measured
# set turned out slower than the sounds it replaced; this one is deliberately
# quicker than the originals. Both generate into the same event directories, so
# they end up as interchangeable takes and Tymer picks between them at random.
#
# @name below labels every file in this set `brisk-N.wav`, which is what keeps
# it from colliding with the measured set's text-derived filenames.
#
# Regenerate: see sound-prompts/README.md

@voice Gacrux
@name brisk
@profile Tymer — the timekeeper
@scene
A quiet home workspace in the late afternoon. One person, deep in a focus
session. The timekeeper is not in the room — it is a steady voice that only
speaks when a moment has been reached, then stops.
@style
Empathetic. Genuinely on the listener's side — warm, understanding, never
scolding. Says it once, kindly, and gets out of the way.
@pace
Rapid fire. No gap at all between sentences, no breath before the last word,
no trailing off. Get in, say it, get out.
@accent Transatlantic.
@context
The timekeeper marks the passage of a work or break period out loud. It
interrupts someone who is concentrating, so it stays short and gets out of
the way quickly.

# overtime (work) — escalation carried by intensity, not by slowing down
# ---------------------------------------------------------------------------

@text [urgently] The scheduled time concluded forty-eight minutes ago. [insistent] All work on this task must stop now.
